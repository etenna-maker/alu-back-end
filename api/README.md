# API

Python scripts that pull employee TODO data from the JSONPlaceholder REST API
and export it to CSV and JSON.

- `0-gather_data_from_an_API.py` - prints an employee's TODO list progress
- `1-export_to_CSV.py` - exports an employee's tasks to `USER_ID.csv`
- `2-export_to_JSON.py` - exports an employee's tasks to `USER_ID.json`
- `3-dictionary_of_list_of_dictionaries.py` - exports all tasks to `todo_all_employees.json`
